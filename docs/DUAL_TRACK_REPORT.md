## 七、根因修正与基建

1. **预热窗口截断（360d → 540d）**：最长因子窗口 252 交易日 > 360 日历天（≈242 交易日），
   2026 年 1 月上旬截面排序落在 LightGBM 缺失值分支（与完整历史排序相关性 0.89-0.98，
   2 月起收敛 1.0），期初簿形漂移并复利放大。修复：`paper.warmup_calendar_days: 540`。
   验证：全历史重放 B_5_5_gov = +7.61% 累计 vs 360d 预热 +5.31%。
2. **gross_exposure NaN**：持仓中停牌个股当日无收盘价时，日报 gross 计为 NaN（入库为 0）——
   修复为按 `settle` 语义跳过无价持仓；红线敞口计算同步加 NaN 防护。
3. **红线 regime 基准**：多空失衡红线改为「超出簿形设计基准的敞口」（regime 空腿收缩/长多簿形
   均有设计基准），不再把设计内失衡报 critical；趋势切换文案区分长多/多空。
4. **特征缓存**：`outputs/cache/ml_book_features/` 按（工件公式+universe+切片起点）哈希缓存，
   每日影子运行只增量计算新 K 线尾部；多账户刷新提升为 union 一次；`refresh_sentiment` 同日跳过；
   PAICC 影子调度超时 3600s → 7200s。

## 九、D 轨实时盘中交易（2026-09-04 起，实盘式逐分钟执行）

**规则：日内操作必须是实盘实时行为——不对过去已知时点买卖，持仓盈亏逐分钟刷新，
成交时间精确到分钟。** 自 `2026-09-04` 起 D 轨日内止损由实时交易服务执行，
收盘回放不再对该日及以后的历史时点补做交易。

### 9.1 架构（shadow → live 直连，零重放）

- `cli.py live`（`src/live/trader.py`）：交易日 09:30-15:10 逐分钟轮询 AlphaFeed
  分钟K最新成交价（当前 bar = 真实成交打印，非历史回放），价格跌破止损即**当场**卖出；
  成交记录 `HH:MM:SS` 分钟级时间戳直接落库；每轮把持仓按最新成交价标记盈亏并写
  `outputs/live_<account>.json`（PAICC 面板实时展示）。
- 仅盘中**卖出**（入场仍在收盘，T+1 结构性安全）；卖出 = 全额清仓（零股合规）。
- 17:30 收盘任务合并当日实时成交（runner 会先应用账本中已有成交再重平衡），
  对 `pb_live_intraday_from` 及以后的日期**跳过日内回放扫描**——绝不重复交易过去时点。
- 触发语义 = "最新成交价 ≤ 止损价"（确认式破位，无插针歧义；开盘 30 分钟豁免、
  当日回补封锁与回放口径一致）。
- 并发安全：收盘运行对当日账本做 seq 水位保护（`protect_after`），运行中途
  实时交易新追加的成交不会被幂等重写删除。

### 9.2 PAICC 面板

- 调度新增 `quant_live_start`（工作日 09:25 拉起实时交易进程，pid 锁防双开）。
- `/quant/live` 端点 + D 轨标签页「盘中实时（逐分钟）」卡片：实时权益/现金/
  仓位占比 + 逐仓现价/入场价/止损价/盈亏，30 秒轮询。

### 9.3 合规口径（与回放同口径）

成交价 = 最新成交价 × 滑点折价并 0.01 tick 化；费用 = 真实成本模型（佣金 2.5bp
最低 5 元 + 卖出印花税 5bp + 过户费 0.1bp）；整手/零股清仓/涨跌停规则沿用合规执行器。
