# ADR-0004: Universe from Baostock, AlphaFeed for prices

The survivorship-safe universe comes from Baostock: yearly `query_all_stock(day)` snapshots unioned with per-code `query_stock_basic` (ipoDate/outDate), stored as `record_type="universe"` records in the shared `pit_records` table. This keeps universe/fundamental/price records queryable through one PIT predicate and lets the B4 check prove that names delisted after a past date T were present in the universe at T. AlphaFeed's `quotes.get(universes="CN_Stock")` CAN list the current ~5539 names, but it has no ipoDate/outDate history, so it is used only as a cross-check, not the survivorship source. Two mandatory filters: Baostock `query_all_stock` mixes indexes and stocks (sh.000001 = 上证指数), so only `type=='1'` rows are kept; and BJ (北交所) symbols are excluded from the AlphaFeed price pass (AlphaFeed returns empty for them, silently).
