# 幸存者偏差压力测试（BIAS STRESS）—— 自进化闭环的阻断判据

> 建立于 2026-09-09。回答一个问题：**在开启 alpha 层自进化闭环之前，数据底座里的幸存者
> 偏差是否小于 0.3 × 目标 alpha（0.3 × 8pp = 2.4pp/yr）？** 若偏差大于阈值，闭环会把
> 偏差当成 alpha 学走。
>
> 工件：`outputs/bias_stress_oos_2025h2_v1.json`（脚本 `scripts/bias_stress_test.py`，
> 离线单测 `tests/test_bias_stress.py`）。相关：`docs/D_TRACK_EVIDENCE.md`、
> `scripts/d_oos.py`、`outputs/d_oos_oos_2025h2_v3.json`。

**结论（一句话）**：在**已测量的退市通道**上，偏差上限为 **1.75pp/yr = 0.22 × 目标 alpha**，
低于 2.4pp 阈值 → **不阻断**；但该结论窄（实测退市率是盈亏平衡退市率的 **73%**），
且**指数成分通道（用今天的 HS300+ZZ500 名单跑 2025 窗口）无法测量**，故闭环仍**不得开启**，
除非先补上历史成分数据或接受 L=-80% 情形（2.80pp，阻断）。

---

## 一、方法

四段测量，全部落进 `outputs/bias_stress_<label>.json`：

| 段 | 内容 | JSON 键 |
| --- | --- | --- |
| 1 | 缺失标的量化（零 K 线 universe 标的、D 池重叠、快照覆盖、名称） | `missing_names` |
| 2 | 盈亏平衡拖累模型（`entries_per_year · x · (1/k) · L` 网格 + 盈亏平衡 x） | `drag_model` |
| 3 | 经验退市率上界（universe 快照）+ ST/低价/低流动性代理 | `hazard`、`risk_proxies` |
| 4 | 生产同构双跑（baseline vs 去偏差子集） | `runs`、`debiased_run` |

判据（`verdict`，键名固定）：

```
threshold_pp          = 0.3 × target_alpha × 100        = 2.4
x_upper_bound         = h_annual × (max_hold / 252) × 1
drag_at_upper_bound_pp= entries_per_year × x_upper_bound × (1/k) × |L_mid| × 100
bias_vs_alpha_ratio   = drag_at_upper_bound_pp / 8.0
bias_blocking_evolution = drag_at_upper_bound_pp > 2.4
```

`drag_at_upper_bound_pp` 用**正号表示年度收益损失**（便于直接与 2.4 比较）；`drag_model.grid`
里按公式原样保留**带符号**值（负 = 损失），两处口径都写在 `verdict_context` 里。

### 运行命令

```powershell
# 完整（两次生产同构回放 + 一次市场构建）：实测 526s，低于 10 分钟预算，窗口无需缩短
python scripts/bias_stress_test.py --label oos_2025h2_v1

# 只做 1/2/3 段（用只读生产账本估计 entries_per_year，不跑回放）
python scripts/bias_stress_test.py --label <name> --skip-runs

# 复用已记录的回放结果重出 JSON（秒级；不重跑簿）
python scripts/bias_stress_test.py --label oos_2025h2_v1 --reuse-runs oos_2025h2_v1

python -m pytest tests/test_bias_stress.py -q     # 30 个离线单测
```

### 数据与隔离口径

* 行情/名单来自 PIT 库 `data.pit_database_url`（`pit_records`），价格 payload 键
  `open high low close raw_close volume amount adjust_factor name`。**`close` 是复权价、
  `open/high/low` 是原始价**（已知混合口径缺陷）；本测试的判定口径**只用 `raw_close` 与
  `amount`**，不受该缺陷影响。
* 两次回放完全照 `scripts/d_oos.py` 的隔离模式：
  `_shadow_cycle(cfg, symbols, start, end, seed, skip_refresh=True, control_scale=<kill-switch>,
  account=<配置里的 D_5W>, ledger_override=outputs/_bias_scratch/<label>_<run>.sqlite,
  write_artifacts=False, probe=probe, market_override=<同一个 market>)`。
  每次运行前断言**临时账本不存在**；运行后断言 `params_match_production`
  （与**配置账户**构建的探针比对 `params_hash`）。
* 生产账本 `outputs/shadow_ledger_D_5W.sqlite` **只以 `mode=ro` 只读打开**（用于
  `--skip-runs` 的 entries 估计），生产 status/report/preclose 文件一律不写。
* **市场只构建一次**（800 名、609 根 K 线、首日 2024-03-11、末日 2026-09-09、耗时 496s），
  两次回放共用同一 `market_override`，因此两跑看到同一数据切片。

## 二、第 1 段：缺失标的量化（`missing_names`）

| 项 | 数值 |
| --- | --- |
| universe 标的数（`record_type='universe'` 去重） | **5435** |
| 其中有 ≥1 根 K 线的 | **5163** |
| **零 K 线的 universe 标的** | **272（5.00%）** |
| ├ 退市型（在 2015-01-05 快照、**不在** 2026-08-07 快照） | **230** |
| └ 新股型（在最新快照、但从未入库 K 线；代码 0012xx/0013xx/3015xx/6034xx/6886-6888xx） | **42** |
| 其中位于 **D 轨 800 名池**内 | **0** |
| 其中位于**覆盖窗口的 universe 快照**内 | **0**（见下） |
| 缺失集合 `valid_from` 区间 | **2015-01-05 … 2026-08-07** |
| 名称含 `退`/`ST` 的缺失标的 | **203 / 272（74.6%）** |

**“覆盖窗口的快照”是 0，因为库里没有覆盖窗口的快照**：`universe` 记录只有两个日期——
`2015-01-05`（2594 名）与 `2026-08-07`（5205 名），且 `valid_to` 均为次日（1 天有效期）。
因此按 PIT 语义：

* `store.universe_as_of("2025-09-01"|"2025-12-31", "universe")` → **0**（窗口内无快照可见）；
* `store.delisted_symbols("2025-09-01", "universe")` → **0**（过去集合为空）；
* `store.delisted_symbols("2015-01-05", "universe")` → **230**（这才是真正的退市集合）。

> 这本身就是一个**必须记录的缺口**：universe 快照是“市场级名单”而非“年度成分”，
> 窗口（2025-09…12）在库里**没有任何成分快照**。第 3 段的退市率因此只能用
> 2015→2026 的 11.6 年跨度外推。

缺失名称样例：`000004.SZ 国华退`、`000005.SZ ST星源`、`000018.SZ 神城A退`、
`000022.SZ 深赤湾A`、`000023.SZ *ST深天`、`000024.SZ 招商地产`、`000033.SZ 新都退`、
`000038.SZ 大通退`、`000040.SZ *ST旭蓝`、`000043.SZ 中航善达`。

**要点**：272 个零 K 线标的**一个都不在 D 轨 800 名池里**——D 池由
`resolve_shadow_universe(cfg,"hs300_500")` 解析（HS300+ZZ500 现役名单），800 名全部有完整
K 线。所以**“持仓标的 K 线缺失”这条直接通道对 D 轨结构性为 0**；第 2/3 段的边界是把它当成
“如果 D 轨从全市场池里选股”的压力情形。

## 三、第 2 段：盈亏平衡拖累模型（`drag_model`）

D 轨形状：`k=6` 槽、每槽 `1/k` 权益、`rebalance_days=1`、`max_hold=40`、`full_invest=true`
（`configs/master_config.yaml` → `shadow.accounts[D_5W]`）。

**`entries_per_year` = 165.95**，来源 = 本次窗口 baseline 回放的真实买入成交数：
**54 笔入场 / 82 个交易日** → 54 × 252/82 = 165.95。
（`--skip-runs` 时的回退口径：只读生产账本 `outputs/shadow_ledger_D_5W.sqlite`，
2026-01-05…2026-09-09 共 134 笔买入 / 167 日 → **202.2/yr**。）

年度拖累 = `entries_per_year · x · (1/k) · L`（pp/yr，负 = 损失）：

| x \ L | −0.30 | −0.50 | −0.80 |
| --- | --- | --- | --- |
| 0.001 | −0.83 | −1.38 | −2.21 |
| 0.002 | −1.66 | −2.77 | −4.43 |
| 0.005 | −4.15 | −6.91 | −11.06 |
| 0.010 | −8.30 | −13.83 | −22.13 |
| 0.020 | −16.60 | −27.66 | −44.25 |
| 0.050 | −41.49 | −69.15 | −110.63 |

盈亏平衡 `x`（拖累 = 阈值）：

| 阈值 | L=−0.30 | L=−0.50 | L=−0.80 |
| --- | --- | --- | --- |
| **0.3 × alpha = 2.4pp** | **0.2892%** | **0.1735%** | **0.1085%** |
| 1.0 × alpha = 8.0pp | 0.9641% | 0.5785% | 0.3616% |

读法：**每约 576 次入场里只要有一次落在“注定退市”的标的上（x>0.17%，L=−50%），
年度拖累就吃掉 2.4pp** —— 这已经是目标 alpha 的 30%。

## 四、第 3 段：经验退市率上界（`hazard`）

从最老快照（2015-01-05）到最新快照（2026-08-07），跨度 **11.5866 年**：

| 口径 | 期初标的 | 期末消失 | 期间消失率 | **年化消失率** |
| --- | --- | --- | --- | --- |
| (a) 全库 universe | 2594 | **230** | 8.87% | **0.7981%/yr** |
| (b) D 轨 800 名池（∩ 最老快照） | 490 | **0** | 0% | **0.0000%/yr**（rule-of-three 95% 上界 **0.0528%/yr**） |

* (a) 是**保守（市场级）**口径：230 个消失名里有 131 个名字含 `退`、72 个含 `ST`，
  其余多为并购/更名/代码变更（如 `000024.SZ 招商地产` 被招商蛇口吸收）。
* (b) 是 **D 轨实际池**：490 只在 2015 年就存在且今天仍在 800 名池里的标的，
  **11.6 年零消失**。0 事件不能给出 0 上界，故用 rule of three：`3/(490×11.5866)=0.0528%/yr`。

**上界构造**（`x_upper_bound`，写在 `verdict_context.x_upper_bound_construction`）：

```
x_upper_bound = h_annual × (max_hold / 252) × pick_prob
              = 0.007981 × (40/252) × 1
              = 0.0012668   (0.1267%)
```

* 用 **(a) 市场级退市率**（不是 D 池的 0）→ 保守；
* `40/252` 把“每年”的退市率换成“一次 40 日持仓期间被选中标的消失”的**逐次概率**；
* `pick_prob = 1` → 最坏情形（假设簿可以选到任何一只注定退市的标的）。

**ST/风险代理（800 名 D 池，窗口 2025-09-01…2025-12-31）**：

| 代理 | 数值 |
| --- | --- |
| 最新 `raw_close < 3.00 CNY`（低价/仙股段） | **19 / 800 = 2.38%** |
| 窗口内日 `amount` 中位数处于**全池最低十分位** | **80 / 800 = 10.01%**（阈值 **162,664,158 CNY**） |
| 二者并集（= 第 4 段去偏差剔除集） | **97 / 800 = 12.14%** |

即：**退市风险集中的那段（低价 + 低流动性）占 D 池 12.1%**，也正是第 4 段被剔除的
标的；`x_upper_bound` 已按“最坏情形”把这个比例隐含在 `pick_prob = 1` 里。

## 五、第 4 段：去偏差子集双跑（`runs` / `debiased_run`）

### 去偏差规则（`debias_rule`，客观且确定）

> 剔除 shadow universe 中满足**任一**条件的标的：
> 1. 窗口末日（≤ 2025-12-31）最后一根 K 线的 `raw_close < 3.00 CNY`；
> 2. 窗口内日 `amount` 中位数 **≤** 全池中位数的 10% 分位（线性插值，阈值 162,664,158 CNY）；
> 3. 窗口内无 `amount` 数据（视为流动性最差）。
>
> 结果：剔除 **97** 只 → 去偏差池 **703** 只（其中 19 只低价、80 只低流动性）。

### 两次运行（生产同构、fresh 临时账本、共用同一 market）

| 指标 | baseline（800） | 去偏差（703） | 差（去偏差 − baseline） |
| --- | --- | --- | --- |
| 累计收益 | **+1.64%** | **−1.43%** | **−3.08pp** |
| 年化收益 | **+5.20%** | **−4.40%** | **−9.60pp/yr** |
| Sharpe | **0.396** | **−0.211** | **−0.607** |
| 最大回撤 | **5.00%** | **6.31%** | +1.31pp |
| 成交笔数 | **106** | **128** | +22 |
| 入场笔数 | **54** | **65** | +11 |
| 佣金 | 723.88 | 860.03 | +136.15 |
| 末日权益 | 50,810.30 | 49,271.75 | −1,538.55 |

装配断言（两跑均通过）：`params_hash = 2aaab31dd7d36b36` = **配置账户**指纹
（`params_match_production = true`）、`ledger_was_fresh = true`、
`no_fill_after_window_end = true`、`cost_model_consistent = true`；
`book_class = PullbackPortfolio`、分钟特征包与分钟 provider 均已接线、kill-switch 已接线
（mode=normal, gross=1.0）。

**同构校验**：baseline 复现了可引用的 OOS 工件
`outputs/d_oos_oos_2025h2_v3.json` 的**全部关键数字**——累计 +1.64%、Sharpe 0.40、
maxDD 5.00%、106 笔成交（日内 33 / 收盘 73）。本 harness 与 `scripts/d_oos.py` 同构。

**读法**：去掉“最便宜、最不流动”的 12.1% 之后，OOS 年化从 **+5.20% 掉到 −4.40%**
（−9.60pp/yr）。也就是说 **D 轨的样本外收益集中在这段风险标的里**，而这段正是退市/
幸存者风险集中的地方。这条差值与 2.4pp 阈值同量级甚至更大，因此“退市通道 1.75pp 未超阈值”
**不能**被读成“数据底座对 alpha 无影响”。

**必须一起读的混淆项**：`pb_rank_min = 0.8` 是**在簿自己的 universe 内**做截面百分位
（`PullbackPortfolio` 用 `wide.reindex(columns=syms).rank(axis=1, pct=True)`）。把池从 800 缩到
703 会**重新排名**，因此入场集合本身也变了（去偏差跑反而多 11 笔入场）。该差值
**不等于**“被剔除的 97 只标的的贡献”，而是“换了一个池 + 重新排名”的综合效应。

## 六、判据（`verdict`，键名固定）

```json
{
  "target_alpha_annual": 0.08,
  "threshold_ratio": 0.3,
  "threshold_pp": 2.4,
  "x_upper_bound": 0.0012668253968253968,
  "drag_at_upper_bound_pp": 1.7519,
  "bias_vs_alpha_ratio": 0.219,
  "bias_blocking_evolution": false,
  "verdict_text": "NOT BLOCKING: … The measured hazard is 73% of the break-even hazard 1.09%/yr."
}
```

* **盈亏平衡退市率 = 1.0933%/yr**；实测市场级退市率 **0.7981%/yr = 73%** 的盈亏平衡值。
  只要退市率再高 37%（或 `entries_per_year` 再高 37%）就越过阈值。
* 敏感性（`sensitivity`）：

| 变体 | x | 拖累 @L=−0.50 | 是否阻断 |
| --- | --- | --- | --- |
| **主口径**：市场级 h × 40/252 | 0.1267% | **1.75pp** | 否 |
| 市场级 h，不做持仓期折算（过度保守） | 0.7981% | **11.04pp** | **是** |
| D 池 rule-of-three 上界 × 40/252 | 0.0084% | 0.12pp | 否 |
| 主口径 + L=−0.80 | 0.1267% | **2.80pp** | **是** |

**判据结论**：在**已测量的退市通道**上，`bias_blocking_evolution = false`（1.75pp < 2.4pp）。
但同一份 JSON 同时记录：若按“每次入场承担整年退市风险”的过度保守口径，或按 L=−80% 的
损失假设，判据翻转为**阻断**；且实测退市率已达盈亏平衡值的 73%。

## 七、无法测量的部分（`unmeasured`）

1. **指数成分前瞻通道**：`resolve_shadow_universe()` 返回的是**今天**的 HS300+ZZ500 名单，
   被套用到 2025-09…12 窗口；PIT 库里**没有任何历史成分记录**（`universe` 只有 2015/2026
   两个市场级快照）。这是本仓库数据底座里**最大的未测量偏差通道**，`x_upper_bound` **不覆盖**它。
2. 缺失标的的**流动性/市值**：272 个零 K 线标的完全没有行情，无法判断它们本会落在
   D 池的哪一段（只能说它们不在现役名单里）。
3. 退市损失的真实分布：230 个消失标的中并购/更名占相当比例，其持有人实际收益可能为正，
   `L ∈ {−0.30,−0.50,−0.80}` 是**假设**而非测量。

## 八、限制与假设（`limitations`）

1. 退市率只由**两个**快照（2015-01-05 / 2026-08-07）算出，是 11.6 年的几何均值，
   看不到逐年退市强度的变化（2020 年前后 A 股退市节奏明显不同）。
2. “不在最新快照”≠“退市”：可能是并购、更名、代码变更——只有退市子集才配得上负的 `L`。
3. `entries_per_year` 是单窗口点估计（165.95），拖累与它**线性**相关；
   只读生产账本口径给出 202.2（+22%），对应主口径拖累 2.13pp（仍 < 2.4pp，但余量仅 11%）。
4. 拖累模型把“注定退市”当成**单槽一次 −L**，忽略相关性（同一板块集体退市）、
   停牌流动性、退出路径（连续跌停无法成交）。
5. 去偏差跑的差值含**重新排名**混淆（见第五节末），不是纯粹的“剔除 97 只”的效应。
6. `raw_close` 口径：用未复权收盘价做 3 元门槛；若用复权价（`close`），剔除名单会变
   （复权价历史更小），但低价段的**经济含义**（面值退市风险）对应的是原始价，故选 `raw_close`。
7. 窗口本身（2025-09-01…2025-12-31）是 D 轨的 **OOS 选择窗口**
   （见 `docs/D_TRACK_EVIDENCE.md` §六），不是干净的前向样本。

## 九、对自进化闭环的处置建议

1. **保持闭环关闭**，直到下列任一条件满足：
   * 补入**历史指数成分**（HS300/ZZ500 逐期名单）并重跑本测试的对应通道；
   * 或把本测试的 `--target-alpha` 降到 0.058 以下（使 1.75pp 相对余量 ≥ 30%）——
     即承认现有 alpha 目标本身已被偏差打折。
2. **把本 JSON 作为闭环的准入工件**：`bias_blocking_evolution = true` 时拒绝开启；
   `false` 时也需人工复核 `unmeasured` 是否已被解决。
3. **优先修复数据**（性价比最高）：把 272 个零 K 线标的的历史行情补进 PIT 库，
   并把 `universe` 快照改成**逐期（季度/年度）成分**，这样第 1、3 段都能从
   “两个快照外推”升级为“逐期实测”。
4. 监控指标：每季度重跑一次；若市场级退市率超过 **1.09%/yr**（盈亏平衡值），
   判据自动翻转为阻断。
